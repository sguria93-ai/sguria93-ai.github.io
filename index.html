Problem of the Day
If \(x + \frac{1}{x} = 3\), find the value of \(x^2 + \frac{1}{x^2}\).
সমাধান দেখুন (Show Solution)
প্রদত্ত আছে, \(x + \frac{1}{x} = 3\)।
উভয়পক্ষে বর্গ করে পাই: $$\left(x + \frac{1}{x}\right)^2 = 3^2$$ $$\implies x^2 + 2\cdot x\cdot\frac{1}{x} + \frac{1}{x^2} = 9$$ $$\implies x^2 + 2 + \frac{1}{x^2} = 9$$ $$\implies x^2 + \frac{1}{x^2} = 9 - 2 = 7$$ উত্তর: 7
