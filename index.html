অধ্যায় - ৪
  1. \((2^{2n} - 1)\) যদি \(3\) দ্বারা বিভাজ্য হয়, তবে দেখাও যে, \([2^{2(n + 1)} - 1]\)-ও \(3\) দ্বারা বিভাজ্য হবে।
    ▶ সমাধান দেখুন
    প্রদত্ত শর্তানুসারে, \((2^{2n} - 1)\) রাশিটি \(3\) দ্বারা বিভাজ্য।
    সুতরাং, আমরা লিখতে পারি \(2^{2n} - 1 = 3k\), যেখানে \(k \in \mathbb{Z}\) একটি অখণ্ড সংখ্যা।
    এখান থেকে পাই, \(2^{2n} = 3k + 1\)।
    এখন,
    $$\begin{align*} 2^{2(n + 1)} - 1 &= 2^{2n + 2} - 1 = (2^{2n}\cdot 2^2) - 1 = (4\cdot 2^{2n}) - 1 \\ &= 4(3k + 1) - 1 = 12k + 4 - 1 = 12k + 3 \\ &= 3(4k + 1) = 3k' \end{align*}$$
    [যেখানে \(k' = 4k + 1 \in \mathbb{Z}\) একটি অখণ্ড সংখ্যা]
    অতএব \([2^{2(n + 1)} - 1]\) রাশিটিও \(3\) দ্বারা বিভাজ্য হবে। (প্রমাণিত)
  2. সব \(n \in \mathbb{N}\) এর জন্য \(2n + 7 < (n + 3)^2\) হলে দেখাও যে, \(2(n + 1) + 7 < (n + 4)^2\)।
    ▶ সমাধান দেখুন
    প্রদত্ত বিবৃতিটি হল \(2n + 7 < (n + 3)^2\), যা সকল স্বাভাবিক সংখ্যা \(n \in \mathbb{N}\)-এর জন্য সত্য।
    যেহেতু অসমতাটি যেকোনো স্বাভাবিক সংখ্যার জন্যই সিদ্ধ হয়, সুতরাং \(n\)-এর পরিবর্তে পরবর্তী স্বাভাবিক সংখ্যা \((n + 1)\) বসিয়ে আমরা পাই,
    $$2(n + 1) + 7 < \{(n + 1) + 3\}^2 \implies 2(n + 1) + 7 < (n + 4)^2$$
    অতএব নির্ণেয় অসমতাটি প্রমাণিত হল।
  3. \((2^{3n} - 1)\) যদি \(7\) দ্বারা বিভাজ্য হয়, তবে প্রমাণ করো যে, \([2^{3(n + 1)} - 1]\)-ও \(7\) দ্বারা বিভাজ্য হবে।
    ▶ সমাধান দেখুন
    প্রদত্ত শর্তানুসারে, \((2^{3n} - 1)\) রাশিটি \(7\) দ্বারা বিভাজ্য।
    অতএব, \(2^{3n} - 1 = 7\lambda\) ধরা যাক, যেখানে \(\lambda \in \mathbb{Z}\) একটি অখণ্ড সংখ্যা।
    এখান থেকে পাই, \(2^{3n} = 7\lambda + 1\)।
    এখন,
    $$\begin{align*} 2^{3(n + 1)} - 1 &= 2^{3n + 3} - 1 = 2^{3n}\cdot 2^3 - 1 = 8\cdot 2^{3n} - 1 \\ &= 8(7\lambda + 1) - 1 = 56\lambda + 8 - 1 = 56\lambda + 7 \\ &= 7(8\lambda + 1) = 7\mu \end{align*}$$
    [যেখানে \(\mu = 8\lambda + 1 \in \mathbb{Z}\) একটি পূর্ণসংখ্যা]
    সুতরাং, \([2^{3(n + 1)} - 1]\) রাশিটিও \(7\) দ্বারা সম্পূর্ণ বিভাজ্য হবে। (প্রমাণিত)
  4. \(1\cdot 1! + 2\cdot 2! + \dots + n\cdot n! = (n + 1)! - 1\) হলে, দেখাও যে, \(1\cdot 1! + 2\cdot 2! + \dots + n\cdot n! + (n + 1)(n + 1)! = (n + 2)! - 1\)।
    ▶ সমাধান দেখুন
    প্রদত্ত সমীকরণটি হল \(1\cdot 1! + 2\cdot 2! + \dots + n\cdot n! = (n + 1)! - 1\)।
    এখন বামপক্ষের প্রথম \(n\)-টি পদের সমষ্টির পরিবর্তে এই মান বসিয়ে পাই,
    $$\begin{align*} \text{L.H.S.} &= \{1\cdot 1! + 2\cdot 2! + 3\cdot 3! + \dots + n\cdot n!\} + (n + 1)(n + 1)! \\ &= \{(n + 1)! - 1\} + (n + 1)(n + 1)! \\ &= (n + 1)! + (n + 1)(n + 1)! - 1 \\ &= (n + 1)![1 + (n + 1)] - 1 = (n + 2)(n + 1)! - 1 \\ &= (n + 2)! - 1 = \text{R.H.S.} \end{align*}$$
    অতএব সম্পর্কটি প্রমাণিত।
  5. \((10^{2n - 1} + 1)\) যদি \(11\) দ্বারা বিভাজ্য হয়, তবে প্রমাণ করো যে, \((10^{2n + 1} + 1)\)-ও \(11\) দ্বারা বিভাজ্য হবে।
    ▶ সমাধান দেখুন
    প্রদত্ত শর্তানুযায়ী, \((10^{2n - 1} + 1)\) রাশিটি \(11\) দ্বারা বিভাজ্য।
    সুতরাং ধরি, \(10^{2n - 1} + 1 = 11\lambda\), যেখানে \(\lambda \in \mathbb{Z}\) একটি পূর্ণসংখ্যা।
    এখন,
    $$\begin{align*} 10^{2n + 1} + 1 &= 10^{(2n - 1) + 2} + 1 = 100\cdot 10^{2n - 1} + 1 \\ &= 99\cdot 10^{2n - 1} + (10^{2n - 1} + 1) = 11\cdot 9\cdot 10^{2n - 1} + 11\lambda \\ &= 11(9\cdot 10^{2n - 1} + \lambda) = 11\mu \end{align*}$$
    [যেখানে \(\mu = 9\cdot 10^{2n - 1} + \lambda \in \mathbb{Z}\)]
    যেহেতু \(\mu\) একটি পূর্ণসংখ্যা, তাই \((10^{2n + 1} + 1)\) রাশিটিও \(11\) দ্বারা বিভাজ্য হবে। (প্রমাণিত)
  6. \((15^{2n - 1} + 1)\) যদি \(16\) দ্বারা বিভাজ্য হয়, তবে দেখাও যে, \((15^{2n + 1} + 1)\)-ও \(16\) দ্বারা বিভাজ্য হবে।
    ▶ সমাধান দেখুন
    প্রদত্ত শর্তানুসারে, \((15^{2n - 1} + 1)\) রাশিটি \(16\) দ্বারা বিভাজ্য।
    ধরি, \(15^{2n - 1} + 1 = 16k \implies 15^{2n - 1} = 16k - 1\), যেখানে \(k \in \mathbb{Z}\) একটি পূর্ণসংখ্যা।
    এখন,
    $$\begin{align*} 15^{2n + 1} + 1 &= 15^{(2n - 1) + 2} + 1 = 15^2\cdot 15^{2n - 1} + 1 \\ &= 225(16k - 1) + 1 = 225\cdot 16k - 224 = 16(225k - 14) \\ &= 16m \end{align*}$$
    [যেখানে \(m = 225k - 14 \in \mathbb{Z}\) একটি পূর্ণসংখ্যা]
    যেহেতু \(m\) একটি অখণ্ড সংখ্যা, তাই \((15^{2n + 1} + 1)\) রাশিটিও \(16\) দ্বারা বিভাজ্য হবে। (প্রমাণিত)
  7. \([(12)^n + (25)^{n - 1}]\) যদি \(13\) দ্বারা বিভাজ্য হয়, তবে দেখাও যে, \([(12)^{n + 1} + (25)^n]\)-ও \(13\) দ্বারা বিভাজ্য হবে।
    ▶ সমাধান দেখুন
    প্রদত্ত আছে যে, \([(12)^n + (25)^{n - 1}]\) রাশিটি \(13\) দ্বারা বিভাজ্য।
    ধরি, \(12^n + 25^{n - 1} = 13\lambda\), যেখানে \(\lambda \in \mathbb{Z}\) একটি পূর্ণসংখ্যা।
    এখন,
    $$\begin{align*} 12^{n + 1} + 25^n &= 12\cdot 12^n + 25\cdot 25^{n - 1} = 12(12^n + 25^{n - 1}) + 13\cdot 25^{n - 1} \\ &= 12(13\lambda) + 13\cdot 25^{n - 1} = 13(12\lambda + 25^{n - 1}) \\ &= 13\mu \end{align*}$$
    [যেখানে \(\mu = 12\lambda + 25^{n - 1} \in \mathbb{Z}\) একটি অখণ্ড সংখ্যা]
    অতএব, \([(12)^{n + 1} + (25)^n]\) রাশিটি সর্বদা \(13\) দ্বারা বিভাজ্য। (প্রমাণিত)
  8. যদি \([n^3 + (n + 1)^3 + (n + 2)^3]\) সর্বদা \(9\) দ্বারা বিভাজ্য হয়, তবে দেখাও যে, \((n + 1)^3 + (n + 2)^3 + (n + 3)^3\)-ও সর্বদা \(9\) দ্বারা বিভাজ্য হবে।
    ▶ সমাধান দেখুন
    প্রদত্ত শর্তানুসারে, \(n^3 + (n + 1)^3 + (n + 2)^3 = 9\lambda\), যেখানে \(\lambda \in \mathbb{Z}\) একটি অখণ্ড সংখ্যা।
    এখান থেকে পাই, \((n + 1)^3 + (n + 2)^3 = 9\lambda - n^3\)।
    এখন,
    $$\begin{align*} (n + 1)^3 + (n + 2)^3 + (n + 3)^3 &= 9\lambda - n^3 + (n + 3)^3 \\ &= 9\lambda + (n + 3 - n)\{(n + 3)^2 + n(n + 3) + n^2\} \\ &= 9\lambda + 3(3n^2 + 9n + 9) = 9(\lambda + n^2 + 3n + 3) \\ &= 9\mu \end{align*}$$
    [যেখানে \(\mu = \lambda + n^2 + 3n + 3 \in \mathbb{Z}\) একটি অখণ্ড সংখ্যা]
    সুতরাং, রাশিটি সর্বদা \(9\) দ্বারা বিভাজ্য হবে। (প্রমাণিত)
  9. \(n \in \mathbb{N}\), \(x > -1\) এবং \((1 + x)^n \ge 1 + nx\) হলে, প্রমাণ করো যে, \((1 + x)^{n + 1} \ge 1 + (n + 1)x\)।
    ▶ সমাধান দেখুন
    প্রদত্ত আছে \(x > -1\), যার ফলে \((1 + x) > 0\)।
    প্রদত্ত সম্পর্ক \((1 + x)^n \ge 1 + nx\)-এর উভয়পক্ষে \((1 + x)\) গুণ করে পাই,
    $$\begin{align*} (1 + x)^{n + 1} &= (1 + x)^n(1 + x) \ge (1 + nx)(1 + x) \\ &= 1 + x + nx + nx^2 = 1 + (n + 1)x + nx^2 \end{align*}$$
    যেহেতু \(n \in \mathbb{N}\) এবং বাস্তব সংখ্যার বর্গের ধর্ম অনুযায়ী \(x^2 \ge 0\), তাই \(nx^2 \ge 0\)।
    অতএব, \(1 + (n + 1)x + nx^2 \ge 1 + (n + 1)x\)।
    সুতরাং প্রমাণিত হল যে, \((1 + x)^{n + 1} \ge 1 + (n + 1)x\)।
  10. মনে করো, \(f(n) = n(n + 1)(2n + 1)\); যদি \(f(n)\) সর্বদা \(6\) দ্বারা বিভাজ্য হয়, তবে প্রমাণ করো যে, \(f(n + 1)\)-ও সর্বদা \(6\) দ্বারা বিভাজ্য হবে।
    ▶ সমাধান দেখুন
    প্রদত্ত শর্তানুযায়ী, \(f(n) = n(n + 1)(2n + 1) = 6\lambda\), যেখানে \(\lambda \in \mathbb{Z}\) একটি অখণ্ড সংখ্যা।
    এখন,
    $$\begin{align*} f(n + 1) &= (n + 1)(n + 2)(2n + 3) = (n + 1)(n + 2)[(2n + 1) + 2] \\ &= n(n + 1)(2n + 1) + 2(n + 1)(3n + 3) \\ &= 6\lambda + 6(n + 1)^2 = 6[\lambda + (n + 1)^2] = 6\mu \end{align*}$$
    যেহেতু \(\mu = \lambda + (n + 1)^2 \in \mathbb{Z}\), অতএব \(f(n + 1)\)-ও সর্বদা \(6\) দ্বারা বিভাজ্য হবে। (প্রমাণিত)
  11. \(n \in \mathbb{N}\) হলে গাণিতিক আরোহ নীতির প্রয়োগে নিম্নলিখিতগুলি প্রমাণ করো:
    1. \(1 + 3 + 5 + \dots + (2n - 1)\) \(=\) \(n^2\)
      ▶ সমাধান দেখুন
      মনে করো, বিবৃতিটি \(P(n) : 1 + 3 + \dots + (2n - 1) = n^2\)।
      ভিত্তি ধাপ: \(n = 1\)-এর জন্য, \(\text{L.H.S.} = 1\) এবং \(\text{R.H.S.} = 1^2 = 1\)। সুতরাং \(P(1)\) সত্য।
      আরোহ অনুমান: মনে করো, \(n = m\)-এর জন্য বিবৃতিটি সত্য; অর্থাৎ,
      $$P(m) : 1 + 3 + 5 + \dots + (2m - 1) = m^2 \quad \dots(1)$$
      আরোহ ধাপ: এখন \(n = m + 1\)-এর জন্য পাই,
      $$\begin{align*} 1 + 3 + \dots + (2m - 1) + \{2(m + 1) - 1\} &= m^2 + (2m + 1) \\ &= (m + 1)^2 \end{align*}$$
      [(1)-এর সাহায্যে]
      \(\therefore P(m)\) সত্য হলে \(P(m + 1)\) বিবৃতিটি সত্য।
      সুতরাং গাণিতিক আরোহ নীতি অনুসারে সকল \(n \in \mathbb{N}\)-এর জন্য বিবৃতিটি সত্য। (প্রমাণিত)
    2. \(a + (a + d) + (a + 2d) + \dots\) ( \(n\)-সংখ্যক পদ পর্যন্ত ) \(=\) \(\frac{n}{2}[2a + (n - 1)d]\)
      ▶ সমাধান দেখুন
      শ্রেণিটির \(n\)-তম পদ \(T_n = a + (n - 1)d\)। মনে করো, উক্তিটি \(P(n)\)।
      ভিত্তি ধাপ: \(n = 1\)-এর জন্য, \(\text{L.H.S.} = a\) এবং \(\text{R.H.S.} = \frac{1}{2}[2a + 0] = a\)। অতএব \(P(1)\) সত্য।
      আরোহ অনুমান: মনে করো, \(n = m\) (\(m \in \mathbb{N}\))-এর জন্য বিবৃতিটি সত্য; অর্থাৎ,
      $$a + (a + d) + \dots + [a + (m - 1)d] = \frac{m}{2}[2a + (m - 1)d] \quad \dots(1)$$
      আরোহ ধাপ: এখন \(n = m + 1\)-এর জন্য প্রথম \((m + 1)\)-টি পদের সমষ্টি পাই,
      $$\begin{align*} S_{m + 1} &= \frac{m}{2}[2a + (m - 1)d] + [a + md] \\ &= (m + 1)a + md\left(\frac{m - 1}{2} + 1\right) = (m + 1)a + \frac{m(m + 1)}{2}d \\ &= \frac{m + 1}{2}[2a + md] = \frac{m + 1}{2}[2a + \{(m + 1) - 1\}d] \end{align*}$$
      [(1)-এর সাহায্যে]
      \(\therefore P(m)\) সত্য হলে \(P(m + 1)\) সত্য হয়। অতএব সকল \(n \in \mathbb{N}\)-এর জন্য বিবৃতিটি সত্য। (প্রমাণিত)
    3. \(\sin x + \sin 2x + \dots + \sin nx\) \(=\) \(\frac{\sin\frac{n + 1}{2}x \sin\frac{nx}{2}}{\sin\frac{x}{2}}\)
      ▶ সমাধান দেখুন
      মনে করো, প্রদত্ত উক্তিটি \(P(n)\)।
      ভিত্তি ধাপ: \(n = 1\)-এর জন্য, \(\text{L.H.S.} = \sin x\) এবং \(\text{R.H.S.} = \frac{\sin x \sin(x/2)}{\sin(x/2)} = \sin x\)। সুতরাং \(P(1)\) সত্য।
      আরোহ অনুমান: মনে করো, \(n = m\)-এর জন্য উক্তিটি সত্য; অর্থাৎ,
      $$\sin x + \sin 2x + \dots + \sin mx = \frac{\sin\frac{m + 1}{2}x \sin\frac{mx}{2}}{\sin\frac{x}{2}} \quad \dots(1)$$
      আরোহ ধাপ: এখন \(n = m + 1\)-এর জন্য পাই,
      $$\begin{align*} S_{m + 1} &= \frac{\sin\frac{m + 1}{2}x \sin\frac{mx}{2}}{\sin\frac{x}{2}} + \sin(m + 1)x \\ &= \frac{\sin\frac{m + 1}{2}x}{\sin\frac{x}{2}}\left[\sin\frac{mx}{2} + 2\cos\frac{m + 1}{2}x \sin\frac{x}{2}\right] \\ &= \frac{\sin\frac{m + 1}{2}x}{\sin\frac{x}{2}}\left[\sin\frac{mx}{2} + \sin\frac{m + 2}{2}x - \sin\frac{mx}{2}\right] = \frac{\sin\frac{m + 2}{2}x \sin\frac{m + 1}{2}x}{\sin\frac{x}{2}} \end{align*}$$
      [(1)-এর সাহায্যে]
      \(\therefore P(m)\) সত্য হলে \(P(m + 1)\) সত্য। অতএব আরোহ নীতি অনুযায়ী সকল \(n \in \mathbb{N}\)-এর জন্য এটি সত্য। (প্রমাণিত)
    4. \(\sin x + \sin 3x + \dots + \sin(2n - 1)x\) \(=\) \(\frac{\sin^2 nx}{\sin x}\)

  12. স্বাভাবিক সংখ্যা \(n\)-এর মানসমূহ নির্ণয় করো যাতে \(2^n > 2n + 1\) অসমতা সিদ্ধ হয়।
    ▶ সমাধান দেখুন
    \(n\)-এর প্রাথমিক স্বাভাবিক মান পরীক্ষা করে পাই:
    • \(n = 1\)-এর জন্য, \(2^1 = 2 \not> 2(1) + 1 = 3\) (অসত্য)
    • \(n = 2\)-এর জন্য, \(2^2 = 4 \not> 2(2) + 1 = 5\) (অসত্য)
    • \(n = 3\)-এর জন্য, \(2^3 = 8 > 2(3) + 1 = 7\) (সত্য)
    মনে করো, \(2n + 1 < 2^n\) যখন \(n \ge 3\)—বিবৃতিটি \(P(n)\) দ্বারা সূচিত হয়।
    স্পষ্টতই, \(P(3)\) বিবৃতিটি সত্য।
    এখন, মনে করো \(P(m)\) বিবৃতিটি সত্য;
    অর্থাৎ,
    $$P(m) : 2m + 1 < 2^m, \quad m \ge 3 \quad \dots(1)$$
    যেহেতু \(m \ge 3\), সুতরাং \(2 < 2^m \quad \dots(2)\)।
    এখন,
    $$\begin{align*} 2(m + 1) + 1 &= 2m + 1 + 2 \\ &< 2^m + 2^m \\ &= 2\cdot 2^m = 2^{m + 1} \end{align*}$$
    [(1) ও (2)-এর সাহায্যে]
    \(\therefore P(m + 1) : 2(m + 1) + 1 < 2^{m + 1}\) বিবৃতিটি সত্য।
    যেহেতু \(P(m)\) সত্য হলে \(P(m + 1)\) সত্য হয়, সুতরাং গাণিতিক আরোহ নীতির প্রয়োগে পাওয়া যায়, \(n \ge 3\)-এর জন্য \(P(n)\) সত্য।
    অতএব, নির্ণেয় মানসমূহ: \(n \ge 3\), যেখানে \(n \in \mathbb{N}\)।
